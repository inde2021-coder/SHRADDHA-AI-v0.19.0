# v0.9.1 — Kids Universe and Person Memory

## Implemented in this source update

### Kids Universe
- Separate Android workspace for 0–6 year stages: 0–6 months, 6–12 months, 1–2, 2–3, 3–4, 4–5 and 5–6 years.
- Optional child nickname and guardian fields, age stage and daily learning goal.
- Age-wise starter curriculum and lesson guidance covering sensory play, language, early numeracy, phonics, stories, puzzles, science observation and school readiness.
- Abacus roadmap with bead values, number representation, addition/subtraction foundations, visualization introduction and optional accuracy practice.
- Mind activities: matching, visual memory, patterns, sorting, maze, story completion, listening and observation.
- Parent-entered care journal for feeding, sleep, diaper, hygiene, play and appointment/medicine notes.
- Child profile and care journal are stored locally using AES-GCM with an Android Keystore key. Delete controls are provided.

### Person Memory
- Consent-gated local person directory with name, relationship/introduction and optional notes.
- Encrypted local storage and delete controls.
- Clear UI disclosure that the current build does not yet perform biometric face identity matching or speaker voiceprint recognition.

## Important limitations — not implemented in v0.9.1

- This is a starter learning curriculum and caregiver journal, not a licensed preschool curriculum, pediatric record system, medical device, emergency monitor, or developmental diagnostic tool.
- It does not run background baby monitoring, cry analysis, sleep detection, feeding detection, camera surveillance or microphone surveillance.
- Face detection is not face identity recognition. Speech-to-text is not speaker identity recognition. Actual face/voice biometric matching still needs vetted on-device embedding models, explicit biometric consent, anti-spoof/liveness measures, thresholds, accuracy testing and an audited deletion lifecycle. No name is inferred from an unknown photo or voice in this build.
- MYRA desktop and Lia Android sources remain preserved as separate integration sources; this update does not claim that all their modules are merged into the native app.
- A full Android build and device QA could not run in this environment because Android SDK/Gradle distribution were unavailable and network DNS prevented downloading Gradle 8.11.1.

## Privacy notes

Child and person data are encrypted at rest in app-private SharedPreferences using AES-GCM and a non-exportable Android Keystore key. Data remains on this device in this version. Uninstalling the app or clearing app data may make the encryption key/data unavailable. Do not store medical secrets or sensitive details unless necessary and authorized. Use a qualified pediatric professional for health concerns.

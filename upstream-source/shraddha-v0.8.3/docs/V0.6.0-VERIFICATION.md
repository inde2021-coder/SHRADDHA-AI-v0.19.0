## Important boundaries
- Offline command matching is a small fixed grammar, not an offline LLM or always-listening wake-word system.
- Local retrieval is keyword-based RAG-lite, not semantic vector search.
- Memory is encrypted locally and does not sync between phones.
- The summarization and provider status routes require the backend and its gateway token configuration.

# MYRA ULTRA ↔ Shraddha AI Device Link

MYRA ULTRA remains a Windows desktop assistant. This integration adds a Device Link dock inside the MYRA main window and starts the existing Shraddha PC companion as a separate, isolated process. Android does not package MYRA's Python, PyQt or Node.js runtime.

## Connect

1. Deploy the Shraddha relay with HTTPS/WSS and configure the same relay URL in the Android app's Device Universe.
2. Install the Shraddha PC companion core dependencies from `desktop-companion/shraddha-pc-companion/requirements.txt` (Python 3.10+).
3. Open MYRA ULTRA → **Device Link** → **Show Shraddha ↔ MYRA connection**.
4. Enter the HTTPS relay origin and the six-digit single-use pairing code generated by the Android owner device. The code is passed to the child process through its environment, not command-line arguments. Leave it blank to reuse a saved Windows Credential Manager pairing.
5. Select **Connect securely**. The companion remains a separate process; its connection and approval messages are shown in the dock. Select **Disconnect** to stop it.

The MYRA dock does not grant remote-control permissions. The existing Shraddha PC companion still requires PC-side approval for each control session and per-action approval. Typing, OCR, screen sharing, file transfer and offline-model features remain governed by the companion's separate opt-in flags and dependency packs.

## Packaging and dependencies

- Source mode locates `../shraddha-pc-companion/shraddha_pc_companion.py` beside the MYRA source folder and starts it with the current Python interpreter.
- A packaged MYRA installation can use a separately built `ShraddhaAI-Desktop-Companion.exe` placed beside the MYRA executable. This keeps the PC companion's optional automation packages out of the MYRA bundle.
- MYRA's Android counterpart does not include these desktop dependencies; it communicates with the relay using its existing Android implementation.
- The pairing code is never stored by the MYRA dock. The companion stores its device token in Windows Credential Manager, as before.

## Security boundaries

Only HTTPS relay origins are accepted. The integration rejects URLs with credentials, query strings, fragments or paths. Pairing codes must be exactly six digits and are supplied to the child process through an environment variable rather than the process argument list. No shell is used to start the companion. MYRA does not execute remote actions itself; all remote actions are handled by the existing Shraddha PC companion and its allowlists, mutual E2E fingerprint confirmation and local approvals.

The PC companion is a separate process and may continue reconnecting until **Disconnect** is selected or the process is stopped. Keep the PC user present during remote-control sessions. Do not enable unattended control on shared or public computers.

# Shraddha AI Desktop Bridge (experimental)

A consent-first Windows/Linux/macOS relay client. It pairs with the same HTTPS/WSS relay used by the Android app. It is a separate companion process, not a merged MYRA runtime.

## Setup

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python bridge.py --relay https://YOUR-RELAY.example --code 123456 --name "My PC" --allow-control
```

Use the six-digit pairing code generated by Shraddha AI. Keep the terminal visible. Incoming remote-control sessions require a local yes/no approval; each remote action also requires local confirmation. The action set is intentionally small and uses an allowlist for app launching. Do not run this on a shared/public computer.

Screen and camera streaming, arbitrary shell execution, file deletion, admin elevation, unattended access, and background persistence are intentionally not implemented.

## Security

- HTTPS/WSS relay only; per-device bearer token is kept in process memory.
- Pairing code is short-lived and one-time/session-limited by the relay.
- Explicit `--allow-control`, target-side session approval, and per-action local approval are required.
- No password/OTP capture, covert screen/camera capture, or arbitrary command execution.
- Disconnect with Ctrl+C. Revoke remote control from the Android sharing-permissions screen.

This is an experimental bridge. Test only with devices you own and verify relay TLS and access controls before use.
